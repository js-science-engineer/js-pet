# 常见问题

## 安装与启动

### Windows 提示"Windows 已保护你的电脑"，是病毒吗？

不是。这是因为安装包**没有购买代码签名证书**，Windows 对没有签名的程序都会给这个提示。
处理方式：点 **更多信息 → 仍要运行**。如果你不放心，可以按
[从源码构建](05-从源码构建.md) 自己编译一份。

### 杀毒软件报毒 / 拦截怎么办？

个别杀毒软件会对未签名的 Electron 程序误报（尤其是绿色版）。
把 js-pet 加入信任列表即可。安装版一般不会被拦。

### 双击了，但桌面看不到宠物

按顺序检查：

1. **是不是被隐藏了**：点托盘区的 js-pet 图标（可能要展开"^"），或右键图标 → 显示宠物
2. **托盘里也没有图标**：说明没启动起来，重新双击一次；仍不行就打开任务管理器，
   结束掉残留的 `js-pet` 进程再启动
3. **换过显示器或改过分辨率**：宠物可能被留在屏幕外。菜单 → 退出，然后重新启动，
   程序会自动把它拉回可见区域
4. **首次启动慢**：没有独立显卡的机器可能白屏 1~2 秒，稍等一下

### 启动时提示 "Cannot find module 'pngjs'" 之类的错误

这是 v0.1.0 早期构建包的缺陷，**正式发布的 v0.1.0 已修复**。
如果你手上是旧包，请重新下载安装包（或按 [从源码构建](05-从源码构建.md) 自己打一份）。

### macOS 提示"已损坏，无法打开"

未签名包被 Gatekeeper 拦截，不是文件真的损坏。按
[macOS 安装指引](02-安装-macOS.md) 里的三种方法之一放行即可。

## 使用

### 拖动时宠物不跟手 / 拖到一半就断

v0.1.0 已修复该问题（原因：拖拽时指针一旦落到窗口透明区，窗口会切回鼠标穿透，
鼠标事件掉到桌面，拖动就断了）。现在拖拽期间会强制保持"抓住鼠标"。
如果你遇到类似现象，请确认用的是最新安装包。

### 宠物挡住我点其他东西了

正常情况不会：宠物窗口的透明区域是**点击穿透**的，只有鼠标指到宠物本体时才接收点击。
如果确实挡住了（比如宠物站在按钮上），把它拖开，或在菜单里隐藏它。

### 右键宠物没反应 / 面板打不开

先点一下宠物本体（确认鼠标能"抓住"它）再右键。
如果仍在某些全屏游戏里无反应，那是全屏独占模式下的正常现象，先退出游戏即可。

### 它不动了 / 不播放动画

- 它待机时会安静地站着，偶尔才张望或打盹，**这是正常的**
- 心情很低或很饿时动作会变慢、变蔫
- 双击它可以立刻触发一次动作
- 如果彻底点不动，退出后重新启动

### 换了形象后，转过去还是老样子？

不会。上传一张正面图就够用：转身时正/侧/背会复用这张图（侧面做镜像），
招手、打盹也复用，所以不会出现"脸是旧的"这种穿帮。

### 上传的图抠不干净，边缘有一圈底色

换一张背景更干净的原图效果最好：

- 最理想：**纯绿幕**（背景明显偏绿）
- 也很好：**纯白 / 纯灰纯色背景**
- 效果一般：渐变背景、原图自带投影
- 抠不出来：复杂背景（风景、房间、多人合照）

另外注意角色要完整入画、四周留点空白。

### 能同时养两只吗？

不能，程序有单实例锁：重复双击只会让已运行的那只重新显示出来。
想养第二只可以再准备一份放置到别的目录（但数据目录相同，不推荐）。

### 会不会联网？我的数据安全吗？

**全程不联网**，没有任何网络请求（断网可完整使用），也没有账号、埋点、遥测。
全部数据（数值、设置、形象、窗口位置）只存在你本机：

- Windows：`C:\Users\<你>\AppData\Roaming\js-pet\`
- macOS：`~/Library/Application Support/js-pet/`

### 数据会丢吗？

有三重保护，正常使用不会：

1. 原子写入：写一半断电也不会写坏
2. 每 24 小时自动备份，保留最近 5 份
3. 主数据损坏时，启动自动回退到最近的可用备份

最保险的做法是偶尔在面板 → 设置里点一次 **导出数据**，把 JSON 存到别处。

### 怎么让它开机自动出现？

面板 → 设置 → **开机自启**（默认关）。不需要管理员权限。
想取消：关掉开关，或到系统"启动项 / 登录项"里删掉。

### 怎么彻底卸载干净？

1. 菜单 → 退出（先把数据写完）
2. 控制面板 → 程序和功能 → js-pet → 卸载（绿色版直接删 exe）
3. 想连数据一起清掉，删除数据目录：
   - Windows：`C:\Users\<你>\AppData\Roaming\js-pet\`
   - macOS：`~/Library/Application Support/js-pet/`

### 它为什么占一百多兆？内存呢？

因为内置了完整的浏览器内核（Electron），所以安装包约 114MB。
运行内存通常在 100~200MB 之间，属于这类桌面挂件程序的正常范围。

## 其他

### 支持哪些系统？

- Windows 10 1809 及以上 / Windows 11（64 位）
- macOS 11 及以上（Apple Silicon 与 Intel 都支持，dmg 需自行构建）

### 为什么 macOS 没有现成安装包？

dmg 只能在 Mac 上构建（工具链限制），Windows 上无法交叉编译。
仓库里配置和步骤都齐了，在 Mac 上执行 `npm run build:mac` 即可，见
[从源码构建](05-从源码构建.md)。
