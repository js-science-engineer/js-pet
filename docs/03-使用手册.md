## 一、第一次打开

启动后你会看到：

1. **桌面右下角**出现一只奶白渐淡蓝的圆滚滚小家伙（默认 150px 高）
2. 它头顶冒出一句欢迎气泡，告诉你它已经在这里了
3. 屏幕右下角**托盘区**出现一个 js-pet 图标

它不会挡住你操作其他软件：**只有鼠标移到宠物身上时才算"点在宠物上"**，
宠物窗口的透明部分会直接把点击让给你下面的程序。

## 二、和它互动

| 操作 | 效果 | 冷却 |
|---|---|---|
| **单击** | 抚摸：心情 +6、亲密度 +1，它会转头看你并说一句话 | 30 秒 |
| **双击** | 逗它玩：随机做兴奋 / 跳跃 / 跳舞动作 | 无（不加数值） |
| **按住拖动** | 换位置。松手后它会轻轻"落定"一下，位置被记住 | — |
| 鼠标在附近移动 | 它的视线会跟着你的鼠标走 | — |
| 什么都不做 | 它会自己待机：张望、招手、打盹 | — |

**关于冷却**：冷却中再点它，它会**回应你一句话**（比如说"让我歇会儿"），
但数值不会增加；喂食冷却 60 秒、抚摸 30 秒、玩耍 5 分钟。
当天亲密度到上限后，它会说"今天的亲密度满啦，明天再来吧"。

**它还会自己说话**：饿了会说"肚子咕咕叫了…"，心情差会说没精神的话，
升级时会炫耀一下，离线回来会告诉你它饿不饿。

## 三、养成系统怎么算

### 三个数值

| 数值 | 范围 | 变化 |
|---|---|---|
| **饱食度** | 0~100 | 每小时 -3；喂食 +25；玩耍 -8（玩着玩着就饿了） |
| **心情** | 0~100 | 每小时 -2；抚摸 +6、玩耍 +15、喂食 +5 |
| **亲密度** | 累加值 | 抚摸/玩耍/喂食 各 +1；每 30 点升 1 级，最高 **Lv.99** |

### 每日上限

每天通过互动最多获得 **+20 亲密度**（每天零点按本地时间重置）。
到上限后还可以继续互动、数值照样涨，只是当天不再增加亲密度了——
这样"每天来看一眼"和"一天刷到满级"的效果不会差太多。

### 心情状态的表现

| 状态 | 触发条件 | 表现 |
|---|---|---|
| 难过 | 心情 ≤ 10 | 整体变暗、蔫着 |
| 没精神 | 心情 ≤ 30 或 饱食度 ≤ 20 | 动作变慢，说话带抱怨 |
| 正常 | 其他 | 常态 |
| 开心 | 心情 ≥ 80 | 微微发光，更活泼 |

### 离线也会结算

关掉电脑的这段时间它也会饿、会无聊，重新打开时按实际时长补算：

- 每小时按上面的速率衰减
- **最多补算 72 小时**（出门一周回来，它最多只"饿三天"，不会一开门就是 0）
- 补算完会用气泡告诉你它的状态

### 升级

亲密度每满 30 点升一级。升级时会播放兴奋动作并冒气泡，
等级和亲密度进度都能在面板"养成"页签看到。

## 四、面板：三个页签

**怎么打开面板**：右键宠物（或右键托盘）→ **设置…** / **形象管理…**。
两个入口都打开同一个面板，只是默认停在的页签不同。

### 养成页签

- 饱食度条、心情条、亲密度进度（含当前等级 Lv.x）
- 三个互动按钮：**喂食 / 抚摸 / 玩耍**（和菜单里的是同一套逻辑，同样受冷却限制）
- 底部有一句状态提示

### 形象页签

- 形象列表：内置的"**经典小圆**"+ 你上传过的形象
- 点列表里的项即可**切换**（宠物立刻换装，不用重启）
- **上传新形象**：选择图片 → 自动抠图 → 自动生成 → 立即穿上
- **删除**：只能删自己上传的，内置形象不可删；删掉当前形象会自动回到内置形象

### 设置页签

| 项目 | 说明 |
|---|---|
| 宠物大小 | 滑块 100 ~ 260 px，**拖动即时生效**，默认 150 |
| 允许漫游 | 是否让它自己在桌面上溜达，默认关 |
| 开机自启 | 默认关。打开后随系统启动（Windows 是登录启动项，无需管理员权限） |
| 立即备份 | 手动生成一份数据备份，存储时保留最近 5 份 |
| 导出数据 | 把全部数据导出成 JSON 文件（自己选保存位置） |
| 从文件恢复 | 选一个之前导出的 JSON 恢复。**会先校验格式**，文件坏了不会覆盖现有数据 |
| 关于 | 版本号信息 |

## 五、换形象

### 内置形象

内置的"经典小圆"是 js-pet 的原创形象（4 个视角 + 招手 + 打盹共 5 张图），
支持完整的 4 面转身动画。随时可以在形象列表里切回来。

### 上传自己的形象

1. 面板 → 形象 → **上传新形象**
2. 选一张图片（PNG / JPG 均可，**不超过 20MB**）
3. 程序自动处理：抠掉背景 → 去绿边 → 平滑边缘 → 缩放到统一尺寸 → 落地成形象
4. 完成后立即生效，宠物换成新形象

**想抠得干净，原图这样拍/生成最好**：

| 背景 | 效果 |
|---|---|
| **纯绿幕**（背景色明显比红蓝更绿） | 最好，一次到位 |
| **纯白 / 纯灰等纯色背景** | 很好，按"背景饱和度低"识别 |
| 渐变背景、有阴影投射 | 一般，边缘可能残留一圈底色 |
| 复杂背景（风景、房间） | 不推荐，抠不干净 |

**其他要点**：

- 角色尽量**完整入画**（别被裁掉手脚），四周留一点空白
- 一张**正面全身图**就够用：转身时正/侧/背会复用这张图（侧面做镜像显示），
  招手、打盹也会复用，所以不会出现"转过去是另一个形象"的穿帮
- 上传的只是你本机的图片，**不会上传到任何服务器**

> 请自行确保上传图片的合法使用权。js-pet 仓库不附带任何第三方 IP 形象。

## 六、桌面散步

打开方式（任选，都是**开/关**开关）：

- 右键宠物 → **桌面散步**：点一下开始散步，**再点一下立刻停止**
- 面板 → 设置 → **允许漫游**

开启后它会每隔 2.6~5.2 秒自己在桌面上挪一段（每次 40~130px），方向随机；
碰到屏幕边缘会自动往回走。

**想让它停下来，再点一次开关即可** —— 停住后完全不动（正在执行的那一步也会被立刻作废，
不会"刹不住"）。

> 漫游产生的位移**不会**写入磁盘，重启后它会回到你上次**拖动**放好的位置。
> 想让它固定在某个地方，关掉漫游再拖过去即可。

## 七、托盘与菜单

**托盘图标**（Windows 任务栏右下角 / macOS 菜单栏）：

- 左键点图标（Windows）：显示 / 隐藏宠物
- 右键点图标：完整菜单
- 鼠标悬停：显示提示 "js-pet · 桌面电子宠物"

**完整菜单项**（托盘右键、宠物右键共用）：

| 菜单项 | 说明 |
|---|---|
| 显示宠物 / 隐藏宠物 | 随当前状态变化 |
| 喂食 / 抚摸 / 玩耍 | 养成互动，宠物会实时做动作并冒气泡 |
| 睡觉 | 让它打盹（纯动画） |
| 形象管理… | 打开面板并停在"形象"页签 |
| 设置… | 打开面板并停在"设置"页签 |
| 桌面散步 | 开/关开关：点一下开始散步，再点一下立刻停止；与设置里的开关同步 |
| 开机自启 | 勾选框，和设置里的开关同步 |
| 关于 js-pet | 版本信息 |
| 退出 | 真正退出程序（退出前会先把数据写盘） |

## 八、数据保存在哪 / 怎么搬家

### 数据保存在哪

| 系统 | 路径 |
|---|---|
| Windows | `C:\Users\<你的用户名>\AppData\Roaming\js-pet\` |
| macOS | `~/Library/Application Support/js-pet/` |

里面有：

- 主数据文件（养成数值、设置、形象目录、窗口位置）
- `backups/` 最近 5 份自动备份
- `looks/<形象 id>/` 你上传的形象图片

### 三重保护

1. **原子写入**：先写临时文件再原子替换，写到一半断电也不会写坏主数据
2. **自动备份**：每 24 小时自动存一份，保留最近 5 份
3. **自愈**：主数据文件损坏时，启动会自动回退到最近的可用备份，
   数据不会一夜回到解放前

### 换电脑 / 备份

- 面板 → 设置 → **导出数据** → 得到一个 JSON 文件，拷走即可
- 新电脑上装好 js-pet → 设置 → **从文件恢复** → 选择那个 JSON
- 想彻底重置：退出 js-pet，删掉上面那个数据文件夹，重新启动就是全新的一只
- **卸载程序不会删除数据**，需要自己手动删

## 九、退出与开机自启

- **退出**：右键宠物或托盘 → **退出**（会把数据写入完成后再关）。
- **隐藏**（只是想让它别碍事）：菜单第一项"隐藏宠物"，或左键点托盘图标（Windows）。
  宠物窗口没有边框和关闭按钮，不存在"不小心关掉"的情况；
  想让它彻底消失就用"隐藏"，想结束程序就用"退出"。
- **开机自启**：面板 → 设置 → 开机自启 打开即可，不需要管理员权限；
  想取消，把开关关掉，或到系统的"启动项 / 登录项"里删掉。

## 十、小技巧

- 拖延症救星：把宠物拖到屏幕正中间，它就盯着你干活
- 让它去屏幕边角"罚站"：拖到边缘后关掉漫游，它就一直待在那儿
- 想截图给朋友看：双击它，抓跳跃那一帧
- 多显示器：直接拖过去，跨屏正常；换显示器后如果找不到它，
  退出重启一次就会自动回到可见区域
- 不想被人看到：隐藏宠物 + 关掉托盘图标的显示（Windows 托盘设置里可隐藏图标），
  进程仍在后台安静运行
