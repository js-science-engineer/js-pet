# 安装 · Windows

适用于 Windows 10 / 11（64 位）。

## 一、选哪个版本

| 版本 | 文件 | 适合谁 |
|---|---|---|
| **安装版**（推荐） | `js-pet-0.1.0-setup.exe` | 大部分人。装进系统，有桌面和开始菜单快捷方式，可正常卸载 |
| **绿色版** | `js-pet-0.1.0-portable.exe` | 不想装东西、想放 U 盘、或在没有管理员权限的电脑上用 |

两者功能完全一样，数据也保存到同一个位置，可以随时换着用。

## 二、安装步骤（安装版）

1. 从 Releases 页面下载 `js-pet-0.1.0-setup.exe`
2. **双击运行**。如果出现蓝色的"Windows 已保护你的电脑"提示：
   - 点左侧的 **更多信息**
   - 再点右下角 **仍要运行**
   - 出现这个提示是因为安装包没有购买代码签名证书，属于正常现象，不是病毒告警
3. 选择安装位置（默认 `C:\Users\<你>\AppData\Local\Programs\js-pet` 即可）
4. 点击 **安装**，等待几秒
5. 安装完成会自动启动，宠物出现在**桌面右下角**

## 三、绿色版使用

直接双击 `js-pet-0.1.0-portable.exe` 即可，不需要安装、不写注册表。
想让它开机自动出现，在面板 → 设置里打开"开机自启"。

> 绿色版每次启动都会解压到临时目录，首次启动比安装版慢 1~2 秒，属正常现象。

## 四、卸载

**安装版**：控制面板 → 程序和功能 → 找到 **js-pet** → 卸载。
或者：开始菜单 → 右键 js-pet → 卸载。

**绿色版**：直接删掉那个 exe 文件即可。

> 卸载**不会**删除你的养成数据。想彻底清理，再手动删除
> `C:\Users\<你>\AppData\Roaming\js-pet\` 这个文件夹（删了就真的从头开始了）。

## 五、找不到宠物怎么办

1. 看**屏幕右下角托盘区**有没有 js-pet 图标（可能被折叠进"^"里）
   - 左键点它 → 显示/隐藏宠物
   - 右键点它 → 完整功能菜单（第一项就是"显示宠物"）
2. 菜单里点 **显示宠物**，它会回到上次待的位置
3. 如果换了显示器、改过分辨率，宠物可能待在了屏幕外：
   退出 js-pet（托盘右键 → 退出）后重新启动，程序会自动把它拉回可见区域
4. 如果托盘也没有图标，说明进程没跑起来，重新双击一次即可
5. 还是不行：打开"任务管理器"看有没有 `js-pet` 进程，结束它之后再启动一次

## 六、系统要求

- Windows 10 1809 及以上 / Windows 11
- 64 位系统
- 约 250MB 可用磁盘空间
- 不需要联网，不需要 .NET / Java 等任何运行库
