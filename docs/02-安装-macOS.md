# 安装 · macOS

适用于 macOS 11 及以上（同时支持 Apple Silicon 与 Intel）。

## 一、先说明两件事

1. **v0.1.1 暂未提供 macOS 预编译包**。macOS 的 dmg 只能在 Mac 上打包，
   请按 [从源码构建](05-从源码构建.md) 在 Mac 上生成，生成的 dmg 就可以像普通安装包一样分发。
2. **安装包未做代码签名与公证**（Apple 开发者账号 $99/年）。因此首次打开会被
   macOS 的 Gatekeeper 拦下。**这是正常现象**，按下面的方法放行一次即可，之后正常双击启动。

## 二、安装步骤

1. 双击 `js-pet-0.1.1-arm64.dmg`（Apple Silicon，M 系列芯片）
   或 `js-pet-0.1.1-x64.dmg`（Intel 芯片）
   > 不确定芯片类型：左上角苹果菜单 → 关于本机，看"芯片"一栏；写着 Apple M… 就用 arm64。
2. 把 **js-pet** 图标拖进 **Applications（应用程序）** 文件夹
3. 打开"启动台"或"应用程序"，**右键点击 js-pet → 打开**
4. 弹窗会提示"无法验证开发者"，点 **打开**
5. 宠物出现在桌面右下角。之后可以正常双击启动，不再提示

## 三、放行方法（按顺序尝试）

### 方法一：右键打开（推荐）

见上面第 3、4 步。这是最简单的方式，**必须先右键再点"打开"**，直接双击是不行的。

### 方法二：系统设置里放行

如果直接双击后提示"无法打开"或"已损坏"，不要删掉它：

1. 打开 **系统设置 → 隐私与安全性**
2. 向下滚动到底部，会看到"**已阻止使用 js-pet**"的提示
3. 点 **仍要打开**，输入开机密码确认

### 方法三：终端命令（最后手段）

提示"**已损坏，无法打开，你应该将它移到废纸篓**"时用这个：

```bash
sudo xattr -rd com.apple.quarantine /Applications/js-pet.app
```

执行后再次打开即可。这条命令只是去掉"这个文件来自网络"的标记，不改变应用本身。

## 四、macOS 上的注意事项

| 项目 | 说明 |
|---|---|
| 宠物位置 | 默认在**主屏幕右下角**；拖动后位置会记住 |
| 多显示器 | 支持，把宠物拖到副屏也能正常显示 |
| 全屏应用 | 宠物始终置顶，尽量浮在全屏应用之上；不想被打扰可在菜单里"隐藏宠物" |
| 菜单栏图标 | macOS 上是**菜单栏图标**，点开即为完整功能菜单，第一项用来显示/隐藏宠物 |
| 开机自启 | 面板 → 设置 → 开机自启（写入登录项，可在系统设置的"通用 → 登录项"里看到并移除） |
| 数据位置 | `~/Library/Application Support/js-pet/`，卸载应用不会删除数据 |
| 卸载 | 把 js-pet.app 拖进废纸篓；想清空数据再删掉上面的数据目录 |

## 五、为什么不做签名与公证

代码签名需要 Apple Developer Program 会员（$99/年）。js-pet 是免费软件，
v1 阶段选择不签名以控制成本，代价就是需要你手动放行一次。
如果后续用户规模上来，会考虑接入签名与公证，把这个步骤去掉。
