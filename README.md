# js-pet

一只常驻桌面的电子宠物。会饿、会无聊、会跟着你的鼠标看，也可以让它自己在桌面上溜达。

**数据只保存在你自己的电脑上，全程不联网。**

## 一、下载安装

### 当前版本：v0.1.0

| 版本 | 直接下载 | 说明 |
|---|---|---|
| **Windows 安装版（推荐）** | [**⬇ 下载 setup.exe**](https://github.com/js-science-engineer/js-pet/releases/latest/download/js-pet-0.1.0-setup.exe) | 双击安装，自动建桌面/开始菜单快捷方式，可在"控制面板"卸载 |
| **Windows 绿色版** | [**⬇ 下载 portable.exe**](https://github.com/js-science-engineer/js-pet/releases/latest/download/js-pet-0.1.0-portable.exe) | 单文件，双击即用，不写注册表，适合放 U 盘 |
| macOS | 暂无预编译包 | 需要在 Mac 上自行构建，见 [从源码构建](docs/05-从源码构建.md) |

全部版本与历史记录：[**Releases 页面**](https://github.com/js-science-engineer/js-pet/releases)
（仓库根目录只放源码，安装包体积超 GitHub 单文件上限，统一放在 Releases 里）

**安装步骤（Windows）**

1. 点上面的下载链接（或到 Releases 页面）下载 `js-pet-0.1.0-setup.exe`
2. 双击运行；若弹出"Windows 已保护你的电脑"（SmartScreen），点 **更多信息 → 仍要运行**
   （安装包未购买代码签名证书，属正常现象）
3. 选择安装位置（默认即可），点击安装
4. 首次启动后，宠物会出现在**桌面右下角**

**卸载**：控制面板 → 程序和功能 → js-pet → 卸载。
卸载**不会**删除你的养成数据（想彻底清干净见 [使用手册 · 数据在哪](docs/03-使用手册.md#数据保存在哪)）。

> macOS 用户请直接看 [macOS 安装指引](docs/02-安装-macOS.md)，首次打开需要手动放行一次。

## 二、三分钟上手

| 操作 | 效果 |
|---|---|
| **单击**宠物 | 抚摸它：心情 +6、亲密度 +1，会说话回应你（30 秒冷却；冷却中它会回你一句，但数值不涨） |
| **双击**宠物 | 逗它玩：随机做出兴奋 / 跳跃 / 跳舞动作（纯动画，不加数值） |
| **按住拖动** | 把它拖到桌面任意位置，位置会被记住 |
| **右键宠物** | 打开功能菜单：显示/隐藏、喂食、抚摸、玩耍、睡觉、形象管理、设置、桌面散步、开机自启、关于、退出 |
| **左键点托盘图标**（Windows） | 显示 / 隐藏宠物 |
| **右键点托盘图标** | 上表那套完整菜单（macOS 是菜单栏图标，点开即为菜单） |

**把鼠标移到宠物身上才会"抓住"鼠标**；宠物窗口的透明区域不会挡住你操作其他软件。

第一次不知道怎么玩？打开面板（右键宠物 → 设置…），在"养成"页签能看到饱食度、
心情、亲密度、等级，以及喂食 / 抚摸 / 玩耍三个按钮。

## 三、功能一览

### 养成
- **饱食度**：每小时 -3，喂食管够（+25）
- **心情**：每小时 -2，抚摸 / 玩耍 / 喂食都能提（玩耍 +15，但有 5 分钟冷却）
- **亲密度**：互动累积，每满 30 点升 1 级，最高 **Lv.99**
- 每天互动有上限（+20 亲密度/天），避免"一天刷满"
- **离线也结算**：关掉电脑再打开，它会把这几小时的变化算清楚告诉你（最多补算 72 小时）

### 互动与动画
单击抚摸、双击嬉戏、拖动搬位置、右键菜单、说话气泡（它会自己说话，也会报状态）、
视线跟随鼠标、点一下会害羞地转过头。

内置 11 组动作：招手、兴奋、跳舞、跳跃、散步、张望、4 面 3D 转身、打盹、点头……

### 换形象
打开面板 → "形象"页签：
- 内置原创形象"经典小圆"（可随时切换回来）
- **上传你自己的图片**：自动抠背景（纯色背景效果最好，绿幕 / 白底最稳），
  自动缩放到统一尺寸，做成一套可用的宠物形象
- 支持删除自带以外的形象

> 请自行确保上传图片的合法使用权。本仓库不附带任何第三方 IP 形象。

### 桌面散步
开启后宠物会自己在桌面上慢慢溜达（碰到屏幕边缘会转向）。默认关闭。
开关是**开/关**式：点一下开始散步，**再点一下立刻停止**。
开关位置：面板 → 设置 → 允许漫游，或右键菜单里的"桌面散步"。

### 面板与设置
| 设置项 | 说明 |
|---|---|
| 宠物大小 | 100 ~ 260 px 实时生效，默认 150 |
| 允许漫游 | 开关桌面散步 |
| 开机自启 | 默认关闭；打开后随系统启动（Windows 为登录启动项） |
| 立即备份 | 手动生成一份数据备份 |
| 导出数据 | 把全部养成数据导出为 JSON 文件 |
| 从文件恢复 | 从导出的 JSON 恢复（会先校验格式，防损坏数据） |

## 四、数据与隐私

**不联网**：js-pet 不发起任何网络请求，断网可完整使用（可在设置里看到"网络：未使用"）。
**不采集**：没有账号、没有埋点、没有遥测。
**可带走**：设置里一键导出全部数据为 JSON，随时可以搬去别的电脑。

数据位置：

| 系统 | 路径 |
|---|---|
| Windows | `C:\Users\<你的用户名>\AppData\Roaming\js-pet\` |
| macOS | `~/Library/Application Support/js-pet/` |

数据安全机制：
- **原子写入**：先写临时文件再替换，写到一半断电也不会把数据写坏
- **自动备份**：保留最近 5 份，每 24 小时自动备份一次
- **自愈**：主数据损坏时，启动自动回退到最近的可用备份
- **退出必落盘**：从菜单退出时会先把数据写完再关

## 五、从源码运行

```bash
git clone <本仓库地址>
cd js-pet
npm install
npm start
```

其他命令：

```bash
npm test            # 运行全部单元测试（173 项）
npm run smoke       # Electron 冒烟自检：启动宠物窗口+面板窗口并检查接口就绪
npm run build:win   # 打 Windows 安装包 + 绿色版（产物在 dist/）
npm run build:mac   # 打 macOS dmg（必须在 Mac 上执行）
```

> 国内网络构建时，Electron 与 electron-builder 的二进制下载较慢，建议加镜像：
> `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`。
> 详细步骤见 [从源码构建](docs/05-从源码构建.md)。

**环境要求**：Node.js 18+（开发用 22 已验证）、Windows 10/11 x64 或 macOS 11+。

## 六、目录结构

```
src/main/        主进程：窗口、托盘、菜单、IPC、数据存储、形象管线
src/preload/     安全桥：contextBridge 白名单接口（渲染进程碰不到 Node）
src/renderer/    渲染层：宠物窗口 pet/ + 面板窗口 panel/
src/shared/      主/渲染共用的纯逻辑：养成数值、抠图、形象槽位、拖拽状态机
src/assets/      内置形象成品 + 托盘图标 + 绿幕原图（构建期素材）
build/           应用图标（ico / png / @2x）与图标原图
tools/           构建与体检工具：素材归一化、图标生成、冒烟自检
tests/           单元测试（node:test，无需测试框架）
docs/            安装 / 使用 / 构建 / 发布 / 验收文档
releases/        各版本发布说明与本地二进制暂存（二进制不进版本库）
```
