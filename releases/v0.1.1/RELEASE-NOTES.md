# js-pet v0.1.1

> 桌面行为修复版 · 2026-10-09

一只常驻桌面的电子宠物：养成、互动、散步，数据只保存在你自己的电脑上。
**全程不联网，不需要账号。**

这一版是**纯修复版**，把 v0.1.0 之后发现的一批桌面行为缺陷修掉了：宠物漫游时
消失、关掉散步也停不下来、"显示宠物"不回到右下角、形象边缘发暗发脏、拖拽光影
丢失等。功能与 v0.1.0 一致，没有新增玩法。

## 这一版修了什么

- **宠物漫游时突然消失**：位移此前按固定常量算边界、且没有监听显示器变化。改为一律
  按窗口**真实边界**钳制，并监听显示器增减/分辨率与缩放变化，立刻把宠物拉回屏幕内。
- **关掉"桌面散步"也停不下来**：可见性巡检没有容差，150% 缩放下 1~2px 的 DPI 舍入
  误差被当成"越界"，每 5 秒挪一次窗口，而每次挪窗又让窗口尺寸涨 2px，形成永不收敛的
  死循环（实测窗口从 326×406 一路涨到 805×823）。现加入巡检容差 + `setBounds` 显式
  带尺寸 + 尺寸看门狗，宠物真正静止。
- **"桌面散步"可以强制停止了**：点一下开始散步，**再点一下立刻停**。旧实现的"停止"
  若恰好发生在异步途中，那一步仍会移动宠物并把定时器排回来；现改为带 token 失效机制
  的调度器，停止即作废在途步骤。
- **"显示宠物"每次都回到右下角**：旧逻辑只在窗口确实越界时才纠正，窗口"看着合法"时
  点了等于没点。现在每次点击都强制落到**鼠标所在屏幕的右下角**。
- **托盘"显示/隐藏宠物"菜单陈旧**：菜单标签与动作在建菜单那一刻固化，隐藏宠物后不再
  同步，点了像没反应。改为弹出瞬间按最新状态重建。
- **形象边缘发暗发脏**：抠图残留的"角色×背景"混合脏边，在缩小贴图采样时被混入角色，
  浅色壁纸上表现为一圈脏边。新增边缘颜色回渗算法；上传自己的形象同样受益。
- **拖拽"离地光影"丢失**：拖拽时影子缩放变淡、暖光变化与落地回弹此前是死代码
  （CSS 缺规则），已补回。

**其它改进**

- 设置面板提交期间的点击不再被静默丢弃（改为合并暂存后补发）。
- 内置形象重新压缩：5 张贴图 1598KB → 405KB（256 色量化，显示尺寸下视觉无损），
  安装包体积略降。
- 单元测试 113 → 173 项，全部通过。

## 这个版本能做什么

- **桌面常驻**：透明无边框、始终置顶、不占任务栏，只有宠物本体接收鼠标点击（透明区域不挡操作）
- **轻度养成**：饱食度每小时 -3、心情每小时 -2；喂食 / 抚摸 / 玩耍提升数值，亲密度每 30 点升 1 级（上限 Lv.99）
- **离线结算**：关机期间按时长补算（最多 72 小时），回到桌面它会告诉你它的状态
- **互动**：单击抚摸、双击嬉戏、按住拖动换位置、右键菜单、说话气泡、视线跟随鼠标
- **11 组动画**：招手、兴奋、跳舞、跳跃、散步、张望、4 面 3D 转身、点头、打盹等
- **换形象**：内置原创形象"经典小圆"；也可上传自己的图片自动抠图换装（绿幕/纯色背景效果最好）
- **桌面散步**：可选的自动溜达，碰到屏幕边缘会转向；点一下开始、再点一下停止
- **面板**：养成数值可视化、形象管理、宠物大小 100~260px 实时调整
- **系统托盘**：左键显隐，右键完整功能菜单
- **开机自启**（可选，默认关闭）
- **数据安全**：本地 JSON 存储、原子写入、损坏自愈、保留最近 5 份备份、每 24 小时自动备份、一键导出/恢复

## 隐私

- **不联网**：没有任何网络请求，断网可完整使用
- **不采集**：无账号、无埋点、无遥测
- **数据位置**：
  - Windows `C:\Users\<你>\AppData\Roaming\js-pet\`
  - macOS `~/Library/Application Support/js-pet/`
- 卸载程序不会删除数据，想彻底清空需手动删除上述目录

## 已知问题

- macOS 安装包未签名，首次打开需放行一次（属预期）
- 无独立显卡的机器首次启动可能有 1~2 秒延迟
- 个别杀毒软件可能对绿色版误报（未签名所致），加入信任即可
- macOS 的 dmg 需要在 Mac 上自行构建
